# 个人 RPC

在「Agent 钱包」展开「RPC 节点」，选择平台默认或自己的节点。填写 BSC 主网 HTTPS 地址，可以选填支持 `eth_subscribe/newHeads` 的 WSS 地址。测试连接不会切换；「保存并使用」会再次核验后切换。恢复默认只需选择默认并保存。

HTTPS 使用 `eth_chainId`、`eth_blockNumber`、`eth_getBalance` 和只读 `eth_call` 测试，要求 chainId 56。它用于本机或当前账号的余额、持仓、报价、模拟和回执；公共发现、行情、信号及图表数据源不变。不改变 Binance CLI 的签名、权限、广播路径，也不增加每笔交易的节点探测。

默认模式沿用现有连接，不额外解析 DNS 或测试节点。个人配置只在保存或恢复启动时核验并固定公网 DNS 地址，拒绝私网地址和重定向。可选 WSS 用新区块唤醒现有回执观察器；断线后原有轮询仍继续。节点 IP 发生变更时请重新测试保存。无 WSS 时保持原有观察节奏。

本地配置保存在 `.runtime/rpc-settings.json`，公网工作进程在各自的私有 runtime 下保存，文件权限为 0600。完整 URL 不会返回到前端或写入浏览器存储。输入框在保存、关闭设置或账号切换后清空。RPC 服务商可以看到链上读取请求，平台不会发送 Binance 登录凭据给 RPC。

订单或钱包读取进行中不可切换，设置与交易使用同一准入屏障。成功切换会清除旧报价及钱包显示缓存，保留钱包连接、真实交易选择与自动续单设置。测试或保存失败保持当前节点。启动恢复个人配置失败时明确提示并沿用默认节点，用户可重新测试保存。

本功能本身不发送买卖、授权、兑换或其他链上交易。
